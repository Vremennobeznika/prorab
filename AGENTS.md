# Прораб: инструкция исполнителю/агенту
1. Источник приложения находится внутри `prorab-source.zip`. Не считать, что файл ZIP автоматически эквивалентен состоянию Windows CI/релиза.
2. Не публиковать токены внешних ИИ, промпты пользователя, личные файлы, логи переписок и конфигурации с ключами.
3. Сначала развернуть исходники в изолированной тестовой среде, проверить SHA и файлы, затем изучить интеграции, права и вызовы процессов. Никогда не запускать сторонние агентные скрипты из Telegram без ревью.
4. Для агента: состояние задачи, правила и ограничения, контролируемый список файлов, источник фактов, поведение при сбое, подтверждение значимых действий, журнал.
5. Запрещать произвольные команды при отсутствии явного разрешения и ограничений доступа к файловой системе. Управление другими агентами требует изоляции процессов.
6. Публикация Windows-установщика только после CI и фактической установки/запуска/удаления и проверки сохранности данных на Windows.
7. После изменений записывать SHA, состав ZIP, reproducible commands, exit codes, blockers, rollback. Статусы NOT VERIFIED не скрывать.
