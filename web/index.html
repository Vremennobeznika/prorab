    Память и критерии готовности

    Предложения и проверка используют дополнительные запросы к выбранной модели. Предложения сохраняются для этого проекта и применяются только после вашего подтверждения. Специалист может читать файлы проекта; менять их и запускать команды он не может. Его оценка тоже может ошибаться.

    При включении подходящие заметки и прошлые задания этого агента передаются выбранной модели. Это задание тоже станет доступно для следующих запусков с памятью.

    Ход работы

    Журнал запусков и проверок

    Выберите нужную модель, включите её и сохраните. Для облачной модели понадобится её ключ доступа. Ключ сохраняется на этом компьютере. Поле очищается после сохранения, сам ключ остаётся в профиле.

    Память помощников

    Сохраняйте предпочтения и решения явно. Помощник подбирает записи с учётом слов, их форм и небольшого словаря синонимов, если на пульте включена память. Прошлый ответ может содержать ошибки. Не сохраняйте здесь пароли и ключи.

    Если снять отметку, заметка сможет передаваться облачной модели. Хранится она в папке данных на этом компьютере.
