# Пробная Windows-сборка 0.3.4

[Сборка и скачивание установщика](https://github.com/Vremennobeznika/prorab/actions/runs/40244625633).

- Исходный коммит: `2c20ef2f6f856bb842e85d766d7e0281adbf98d4`, ветка `codex/windows-trial`.
- Все этапы job `windows-installer` завершились успешно на `windows-2022`.
- Проверены: тесты исходников, installed-mode HTTP smoke, нагрузочный сценарий с тестовой моделью, создание установщика, комплектность встроенного runtime и лицензии Node.js.
- Настоящий установщик испытан с путями, содержащими пробелы и кириллицу: установка, HTTP UI с авторизацией, 11 агентов, наличие поиска, создание памяти, перезапуск, GUI/tray launcher, удаление и переустановка с сохранением памяти и рабочего файла.
- Артефакт: **Prorab-Windows-Setup**, 21,6 МБ. Это ZIP с `Prorab-Setup-0.3.4.exe`; требуется вход в GitHub для скачивания Actions artifacts.

Для пробы: скачайте артефакт внизу страницы сборки, распакуйте и запустите установщик. Node.js устанавливать отдельно не нужно. Настройте свою модель во вкладке «Модели».

Это пробная сборка: живые ИИ-провайдеры и пользовательские Windows 10/11 пока не проверены. Успех CI не заменяет эту пользовательскую пробу.
