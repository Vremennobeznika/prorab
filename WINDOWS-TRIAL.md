# Пробная Windows-сборка 0.4.0

[Сборка и скачивание установщика](https://github.com/Vremennobeznika/prorab/actions/runs/40246897824).

- Исходный коммит: `b5e1916`, ветка `codex/windows-trial`.
- Все этапы job `windows-installer` завершились успешно на `windows-2022`.
- Проверены: тесты исходников, installed-mode HTTP smoke, нагрузочный сценарий с тестовой моделью, создание установщика, комплектность встроенного runtime и лицензии Node.js.
- Настоящий установщик испытан с путями, содержащими пробелы и кириллицу: установка, HTTP UI с авторизацией, 11 агентов, наличие поиска, создание памяти, перезапуск, собственное окно WebView2 с подтверждённой отрисовкой, удаление и переустановка с сохранением памяти и рабочего файла.
- Артефакт: **Prorab-Windows-Setup**, 23,5 МБ. Это ZIP с `Prorab-Setup-0.4.0.exe`; требуется вход в GitHub для скачивания Actions artifacts.

Для пробы: скачайте артефакт внизу страницы сборки, распакуйте и запустите установщик. Node.js устанавливать отдельно не нужно. Настройте свою модель во вкладке «Модели».

Это пробная сборка: живые ИИ-провайдеры и пользовательские Windows 10/11 пока не проверены. Успех CI не заменяет эту пользовательскую пробу.

Версия 0.4.0 использует собственный движок Прораба: проекты, продолжаемые диалоги, план, выбор модели и делегирование специалисту только для чтения. Проверены 94 теста на Linux и успешный полный Windows CI. [Прямая ссылка на ZIP с EXE](https://github.com/Vremennobeznika/prorab/actions/runs/40246897824/artifacts/12619445116).
