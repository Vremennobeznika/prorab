# Прораб

«Прораб» — локальная диспетчерская ИИ-агентов для Windows.

## Состояние публикации

**Исходный код опубликован:** [скачать архив проекта](prorab-source.zip). Внутри 72 файла, в том числе `src/`, `web/`, тесты и `.github/workflows/windows-build.yml`. Проверена целостность ZIP и 78 автоматических тестов на Linux.

**Готовый установщик пока не опубликован.** Не скачивайте архив исходников в ожидании файла `.exe`: это не установщик.

## Подтверждённая сборка ветки

26.10.2026 успешно завершился [Windows CI](https://github.com/Vremennobeznika/prorab/actions/runs/40358567902) в ветке `codex/prorab-0.4.1-desktop-build`. В запуске создан артефакт `Prorab-Windows-Setup-0.5.1`. Артефакты Actions имеют ограниченный срок хранения; это не постоянная ссылка на релиз и не подтверждение установки на Windows. Архив исходников в `main` не следует считать идентичным этой сборке.

## Сборка на Windows

1. Распакуйте `prorab-source.zip` в отдельную папку.
2. Для CI можно использовать `windows-build.yml` из архива на GitHub Actions (`windows-2022`); он собирает установщик через Node.js 22 и Inno Setup 6.
3. Обязательная проверка до выпуска: успешный CI, установка/запуск/удаление в Windows, сохранение данных и реальная работа с ИИ.

Пользователю готовой версии Node.js не должен требоваться — он входит в установщик. Сборка отдельной ветки подтверждена. До проверки установки, запуска, удаления, сохранности данных и работы с ИИ на Windows готовность к пользовательскому выпуску **не подтверждена**.
