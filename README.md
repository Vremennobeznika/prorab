# Прораб

«Прораб» — локальная диспетчерская ИИ-агентов для Windows.

## Состояние публикации

**Исходный код опубликован:** [скачать архив проекта](prorab-source.zip). Внутри 97 файлов, в том числе `src/`, `web/`, тесты и `.github/workflows/windows-build.yml`. Проверена целостность ZIP и 89 автоматических тестов на Linux.

**Готовый установщик пока не опубликован.** Не скачивайте архив исходников в ожидании файла `.exe`: это не установщик.

## Сборка на Windows

1. Распакуйте `prorab-source.zip` в отдельную папку.
2. Для CI можно использовать `windows-build.yml` из архива на GitHub Actions (`windows-2022`); он собирает установщик через Node.js 22 и Inno Setup 6.
3. Обязательная проверка до выпуска: успешный CI, установка/запуск/удаление в Windows, сохранение данных и реальная работа с ИИ.

Пользователю готовой версии Node.js не должен требоваться — он входит в установщик. До завершения Windows-сборки проект имеет статус **НЕ ГОТОВО**.
