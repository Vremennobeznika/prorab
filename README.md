# Прораб

Программа для поручения задач ИИ-помощникам и работы с файлами. Знание программирования не требуется.

## Как пользоваться в Windows

1. Установите программу из `Prorab-Setup-0.4.1.exe` и откройте ярлык «Прораб».
2. На вкладке **Модели** подключите ИИ. Если нужен ключ доступа, получите его у выбранного сервиса и вставьте в поле.
3. Выберите помощника, опишите задачу и нажмите **Запустить**.
4. Если помощник просит разрешение изменить файл или выполнить команду, проверьте действие и нажмите **Разрешить** или **Отклонить**.

Программа открывается в отдельном окне Windows с системным WebView2. Для выхода используйте значок рядом с часами.

**Файлы и настройки:** `%LOCALAPPDATA%\Prorab`. Данные сохраняются при обновлении и обычном удалении программы.

**Если ИИ не отвечает:** проверьте подключение модели на вкладке «Модели», интернет и правильность ключа. Локальная модель требует отдельно установленную Ollama. Некоторые облачные модели требуют регистрацию или оплату.

**Статус версии 0.4.1:** исходный код и сценарий Windows-сборки. Установщик этой версии ещё требует успешной проверки на Windows. После успешного запуска Actions установщик доступен в артефакте `Prorab-Windows-Setup-0.4.1`.

## Разработчику

- [Техническая документация](DEVELOPER.md): архитектура, конфигурация, безопасность и запуск исходников.
- `src/` — сервер, агенты и модели; `web/` — интерфейс; `test/` и `qa/` — проверки.
- `packaging/` и `.github/workflows/windows-build.yml` — сборка Windows.

Ключи доступа не должны попадать в репозиторий. Они сохраняются в `credentials.json` в профиле пользователя без шифрования; прежние ключи из `.env` также поддерживаются.

## Проекты и диалоги

Версия 0.4 открывает отдельное окно Windows, сохраняет диалоги и планы и поддерживает проверку специалистом. [Инструкция](WORKSPACE.md).

Для проверки исходников используйте Node.js 22 или новее: `npm test`. Windows CI проверяет установку, собственное окно, вставку и сохранение ключа, перезапуск, удаление и сохранность данных после переустановки.
