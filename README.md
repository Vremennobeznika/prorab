# Прораб

«Прораб» — локальная диспетчерская ИИ-агентов для Windows.

## Состояние публикации

**Исходный код опубликован:** [скачать архив проекта](prorab-source.zip). Внутри 109 файлов, в том числе `src/`, `web/`, тесты и `.github/workflows/windows-build.yml`. Проверена целостность ZIP и 97 автоматических тестов на Linux.

**Пробный Windows-установщик 0.4.0 собран:** [скачать артефакт Prorab-Windows-Setup](https://github.com/Vremennobeznika/prorab/actions/runs/40246897824). Внизу страницы сборки откройте Artifacts → Prorab-Windows-Setup, распакуйте ZIP и запустите Prorab-Setup-0.4.0.exe. Архив prorab-source.zip содержит исходники, а не установщик.

## Сборка на Windows

1. Распакуйте `prorab-source.zip` в отдельную папку.
2. Для CI можно использовать `windows-build.yml` из архива на GitHub Actions (`windows-2022`); он собирает установщик через Node.js 22 и Inno Setup 6.
3. Обязательная проверка до выпуска: успешный CI, установка/запуск/удаление в Windows, сохранение данных и реальная работа с ИИ.

Пользователю готовой версии Node.js не должен требоваться — он входит в установщик. Пробная сборка прошла автоматические проверки на Windows 2022: тесты исходников, установка, запуск встроенного Node.js и отдельного окна WebView2, сохранение памяти после перезапуска и переустановки, удаление с сохранением данных. [Результат проверки](WINDOWS-TRIAL.md). Реальные ИИ-провайдеры и работа на пользовательском Windows 10/11 ещё требуют пробы.

## Память и локальный поиск

Добавлены память между заданиями с просмотром и удалением, поиск по прошлым заданиям и файлам, критерии готовности. Описание и источники идей — [MEMORY.md](MEMORY.md). Изменения к исходникам доступны для просмотра в [патче](changes/memory-and-local-search.patch); в ZIP они уже применены.
