# Прораб

Репозиторий подготовлен к загрузке исходного проекта. Публикация исходников и Windows-сборка пока **не завершены**.

В репозитории пока нет исходного кода приложения и исполняемого установщика. Не считайте эту ветку готовым релизом.

Цель: Windows 10/11 x64, один установщик без необходимости устанавливать Node.js, проверка тестов и установки через GitHub Actions.

После загрузки исходников сборка должна пройти модульные тесты, проверку запуска упакованного приложения, установку и удаление на Windows. До этого выпуск не аттестован.
