# Проверка Прораба 0.5.1

Дата: 26 октября 2026. Проверена локальная версия 0.5.0, затем исправления 0.5.1.
Объём — функциональность и надёжность приложения, сохранность данных, интерфейс,
поставка и фактические основания сравнения с Harness. Это не юридическая экспертиза.

## Выявленные и исправленные дефекты

| Приоритет | Дефект в 0.5.0 | Исправление и подтверждение |
| --- | --- | --- |
| P1 | Удалённая заметка повторно передавалась модели через служебную копию в истории диалога | В новые шаги сохраняется только сам диалог; старые служебные подстановки фильтруются при чтении контекста. Проверены новая история и старый файл после повторного открытия |
| P1 | Замечания отдельного проверяющего показывались человеку, но отсутствовали в контексте следующего сообщения | Итог с ревью сохраняется в последнем ответе истории. Тест продолжения видит уникальный маркер замечания |
| P2 | Ограничение с путём «.» не применялось к файлам проекта | Корень нормализуется; тесты корня, подпапки и похожего имени другой папки |
| P2 | Явное сохранение дубликата предложения оставляло запись pending | Существующее предложение принимается с тем же ID; дубль не создаётся |
| P1 | Вторая правка файла в одном запуске затирала исходную резервную копию | COPYFILE_EXCL сохраняет первую версию; проверены исходные байты и CRLF |
| P1 | Остановка сразу после разрешения могла не предотвратить ещё не выполненную запись | AbortSignal проверяется непосредственно перед действием; тест гонки не находит созданного файла |
| P1 | Отменённый запрос ждал освобождения занятой модели | Удаление из очереди при отмене; тест немедленного выхода и сохранения единственного активного слота |
| P2 | Поля темы и пути в памяти имели стандартный мелкий стиль браузера, особенно заметный в тёмной теме | Явный type=text подключает общий стиль; браузерная проверка размеров полей в обеих темах |

Семь логических дефектов воспроизведены восемью тестами: для памяти есть отдельный тест старого
формата. Новые тесты сначала дали отказы на 0.5.0, после исправлений проходят.
Резервные копии и отмена не откатывают уже выполненные действия. Удаление заметки
не удаляет цитаты из ответов модели, созданных файлов и ранее отправленных запросов.

Измерения относятся к конкретному Linux-прогону и тестовой модели. Они не доказывают
производительность внешних моделей, быстродействие на слабом ПК или преимущество
над Harness. Windows CI отдельно проверяет реальный установщик, окно WebView2,
ключ после перезапуска, память после переустановки и TLS с адресами GigaChat;
прохождение TLS не является успешным ответом модели с пользовательским ключом.

## Непроверенное

- Ответы, инструменты, качество извлечения памяти и ревью на реальном GigaChat,
  Ollama и Z.ai: в среде нет пользовательских ключей и запущенной Ollama.
- Чистая Windows 10/11 на реальном компьютере пользователя: доступен Windows Server
  2022 в CI, поэтому его результат не заменяет проверку конкретного ПК.
- Обновление с каждой исторической версией, длительная эксплуатация, физические
  слабые устройства, screen reader и полноценные наблюдения с пользователями.
- Возобновление произвольных дочерних процессов после отмены shell, устойчивость
  ко всем сбоям носителя и полная сертификация безопасности.
- Исполнение Harness: сравнение основано на его исходных документах, не на запуске.

## Воспроизведение

```sh
node --test
node qa/smoke-installed.mjs
node qa/load-agent.mjs
node scripts/perf-audit.mjs
python3 qa/memory-upgrade-browser.py
python3 qa/memory-browser.py
python3 qa/workspace-browser.py
python3 qa/settings-browser.py
python3 qa/visual-offline-browser.py
```

Python-сценариям нужны Playwright и Chromium. Ключи внешних сервисов не требуются.

Вердикт по выполненным локальным проверкам: **ГОТОВО С ОГРАНИЧЕНИЯМИ**.
Выявленные дефекты устранены. Окончательный статус Windows-поставки и ссылка на
установщик — в PR и Actions для соответствующего коммита. Юридическая чистота и
качество ответов реальных ИИ-сервисов этим вердиктом не подтверждаются.
