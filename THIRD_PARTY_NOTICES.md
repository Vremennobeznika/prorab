# Компоненты дистрибутива Прораба

У новых модулей памяти нет внешних npm-зависимостей. Проекты, изученные как источники
идей, перечислены отдельно в [ORIGINS.md](ORIGINS.md); их серверы, SDK и исходный код
не являются зависимостями дистрибутива.

| Поставляемый компонент | Уведомление в установленной программе |
| --- | --- |
| Node.js 22.16.0 и его встроенные компоненты | runtime/NODE-LICENSE.txt, копируется с используемым Node; сборка останавливается, если файл отсутствует |
| Microsoft WebView2 SDK 1.0.2903.40 | WEBVIEW2-LICENSE.txt; SDK проверяется по SHA256, загрузчик Runtime — по подписи Microsoft |
| Шрифты Inter и Manrope | app/web/fonts/Inter-LICENSE-OFL.txt и app/web/fonts/Manrope-OFL.txt (SIL OFL) |
| Публичные CA для GigaChat | app/certs/README.txt; источник, проверка цепочки и отпечатки описаны там и в журнале сборки |

Это инвентаризация прямых компонентов текущей сборки, а не доказательство юридической
чистоты любого будущего изменения. Полные условия компонентов находятся в указанных
файлах. Лицензия Node.js включает уведомления встроенных сторонних компонентов.
