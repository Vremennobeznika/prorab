Сюда кладётся корневой сертификат НУЦ Минцифры — он нужен только для GigaChat.

1. Скачайте сертификат на портале Госуслуг: https://www.gosuslugi.ru/crt
   Нужен файл в формате PEM (внутри текст, который начинается со строки
   -----BEGIN CERTIFICATE-----).
2. Сохраните его в эту папку под именем: russian_trusted_root_ca_pem.crt
3. Если GigaChat всё равно жалуется на сертификат, добавьте в тот же файл ещё и
   «выпускающий» сертификат (Sub CA) с того же портала: просто вставьте его текст
   ниже первого, в этот же файл.

Прораб доверяет этому сертификату ТОЛЬКО при обращении к GigaChat.
Проверку сертификатов для остальных сайтов и провайдеров он не ослабляет.
