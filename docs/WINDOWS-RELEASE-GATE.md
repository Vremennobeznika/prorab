# Приёмка «Прораба» для обычного пользователя

Продукт — Windows-диспетчер ИИ-агентов. На дату ввода этого чек-листа прежняя README не подтверждает готовность установщика к стабильному пользовательскому выпуску.

| Проверка | Критерий | Статус нового цикла |
|---|---|---|
| Исходники | ZIP содержит актуальный проект; hash / tree / версия сопоставлены | NOT VERIFIED |
| Сборка | Windows CI на SHA ветки релиза | NOT VERIFIED |
| Installer | Установка, запуск и удаление без Node.js у пользователя | NOT VERIFIED |
| Процессы | Отсутствие висящих дочерних процессов, отмена и timeouts | NOT VERIFIED |
| Агенты | Явные разрешения на команды, файлы и сеть | NOT VERIFIED |
| Безопасность | Ключи и личные запросы не утекают в релиз/логи | NOT VERIFIED |
| Сохранность | Перезапуск/обновление без утраты проекта | NOT VERIFIED |
| UX | Обычный пользователь может начать без терминала | NOT VERIFIED |
| Rollback | Предыдущая версия и инструкция восстановления | NOT VERIFIED |

Источники методики: безопасно адаптированные handoff, code-review, QA из аудита Telegram. Сторонние агентные команды не импортировались. Этот PR не включает собранный инсталлятор.
