# Проверенное сравнение с DeepSeek Harness

Дата: 26 октября 2026. Прораб: версия 0.5.1. Harness: исходники коммита
[22ddee3792402c3e70ec5f86a63c3e3e895a2f60](https://github.com/deepseek-ai/deepseek-harness/tree/22ddee3792402c3e70ec5f86a63c3e3e895a2f60).
Harness не устанавливался и не запускался: сравнение ниже основано на его документации
и манифесте Desktop, а для Прораба — также на выполненных тестах. Это не benchmark
двух приложений и не утверждение превосходства или юридической уникальности.

| Возможность | Прораб | Подтверждённое у Harness | Вывод |
| --- | --- | --- | --- |
| Движок | Собственный JavaScript-цикл, реестр инструментов и пул моделей; зависимостей Harness/Cordis нет | [Архитектура Cordis, возможности как плагины](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/architecture.md) | Разная архитектура и расширяемость |
| Windows и собственное окно | Inno Setup, Node.js 22.16.0, WinForms/WebView2 | [Electron Desktop с поставляемым runtime и Windows packaging](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/apps/desktop/package.json) | Windows-приложение и встроенный runtime не уникальны; отличается технология окна |
| Сторонние модели | OpenAI Chat Completions, Ollama, отдельный адаптер GigaChat | [Сторонние провайдеры и custom API](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/user/guide/providers.md) | Подключение сторонних моделей не уникально |
| GigaChat | Собственный OAuth, функции, CA в установщике, проверка TLS | В просмотренном руководстве/реестре не найден отдельный штатный адаптер GigaChat; кастомные API и внешние плагины возможны | Подтверждённая особенность нашей поставки; отсутствие во всей экосистеме Harness не доказано |
| Память | Встроенные проектные заметки, предложения с подтверждением, темы/источники и ограниченные сводки | [Подключение внешних MCP-серверов памяти; примеры выключены по умолчанию](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/user/guide/mcp-memory.md) | Отличается готовая поставка и управление памятью; сама долговременная память не уникальна |
| Разрешения | Запись запрашивает разрешение кроме auto; команды всегда с разрешением | [Настраиваемые presets sandbox и approvals](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/subsystems/permission-presets.md) | Разрешения не уникальны |
| Изоляция команд | Встроенные файловые инструменты проверяют границы. Разрешённая shell-команда выполняется с правами пользователя; ОС-песочницы нет | [Документированы backend-ы файловой изоляции для Linux, macOS и Windows с ограничениями](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/subsystems/sandbox.md) | Нельзя приравнивать нашу проверку путей и разрешения к процессной песочнице |
| Специалисты | Опциональный проверяющий только для чтения, два поручения на сообщение | [Подагенты, backend-ы и переопределение моделей](https://github.com/deepseek-ai/deepseek-harness/blob/22ddee3792402c3e70ec5f86a63c3e3e895a2f60/docs/subsystems/subagent.md) | Подагенты не уникальны; различаются конкретные политики и реализация |

Ранее в чате Windows-установщик, встроенный runtime, сторонние модели и разрешения
были перечислены как отличия без проверки текущего Harness. Это было слишком широкое
сравнение: такие возможности есть у обоих. Зафиксированные отличия — конкретный
движок, состав поставки и пользовательские сценарии, а не исключительное право
на общие механизмы агентных программ. Полная совместимость с плагинами Harness
в Прорабе не реализована.
