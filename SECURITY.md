# Безопасность Прораба: границы гарантий

Версия 0.5.2. Этот документ не заменяет проверку установленной сборки.

- **Файлы проекта.** Автоматический `read_file` отклоняет распространённые имена секретов и закрытые каталоги (`.env`, `.git`, `.ssh`, `credentials.json`, `*.key`, `*.pem` и другие). Поиск `search_files` также исключает секреты. Это эвристика: файл с нейтральным названием может содержать ключ. Перед включением облачной модели проверьте папку проекта.
- **Команды.** `run_command` всегда запрашивает разрешение и удаляет известные ключи из переменных окружения, но исполняется с правами текущего пользователя **без песочницы ОС**. Команда может обратиться за пределы проекта и запустить дочерние процессы. Разрешайте только полностью понятные команды.
- **Ключи моделей.** `credentials.json` хранится в локальном профиле в незашифрованном JSON. Не передавайте профиль другим людям; не помещайте ключи в репозиторий, общие папки и синхронизируемые каталоги. Для защиты от других локальных программ нужна отдельная доработка системного хранилища ключей.
- **Доступ.** По умолчанию слушается `127.0.0.1`, доступ требует токена. Режим `--lan` работает по HTTP без TLS: используйте только доверенную локальную сеть и не публикуйте ссылку с токеном.
- **Отмена.** Остановка предотвращает дальнейшие действия агента в контролируемых точках, но уже выполненные команды, файловые изменения и их дочерние процессы не откатываются автоматически.
- **Сборки.** Проверяйте, что GitHub Actions выполнил тесты и сборку для **конкретного коммита**, из которого скачан установщик. Успех предыдущей версии не является проверкой новой.

Перед публичным релизом нужны отдельные проверки Windows 10/11, обновления со старых версий, реального провайдера, хранения секретов и ручная проверка поведения команд.
