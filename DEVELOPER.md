# Техническая документация «Прораба»

Для разработчиков. Обычным пользователям — README.md.

## 1. Демо за три минуты (без моделей)

Откройте терминал в папке проекта:

```
npm run demo
```

Откроется страница. Выберите агента «Помощник по файлам», напишите любую задачу, нажмите «Запустить» — «притворная» модель пройдёт сценарий: посмотрит папку, прочитает `привет.txt` и попросит разрешения дописать строку. Нажмите «Разрешить» (или «Отклонить») и посмотрите, что изменилось.

> В Windows PowerShell может появиться «выполнение сценариев отключено». Тогда запускайте напрямую, без npm: `node scripts/demo.js`. То же касается остальных команд: `npm start` ≡ `node src/main.js`, `npm test` ≡ `node --test`.

## 2. Настоящая работа с локальной моделью

1. Установите [Ollama](https://ollama.com) и скачайте модель: `ollama pull llama3.2`. Скачивание весов зависит от вашего интернета — если оно обрывается, повторите команду (Ollama докачивает).
2. Посмотрите точное имя модели: `ollama list`. Если оно отличается, впишите его в `config/providers.json` в поле `model` провайдера `local`.
3. Запустите: `npm start`. Страница откроется сама; ссылка с токеном напечатана в окне терминала.

Модель должна уметь вызывать инструменты. Маленькие модели (около 3 млрд параметров) делают много ошибок — берите модель побольше, если хватает памяти. «Экзамен» моделей (автоматическая проверка, кто из них справляется) — в планах.

**Слабый компьютер.** Локальная модель без видеокарты отвечает медленно. Время ожидания ответа задаётся полем `timeoutSec` у провайдера в `config/providers.json` (для локальной модели по умолчанию 300 секунд, для остальных 120). Одновременно идёт не больше трёх запусков агентов — предел можно изменить в `config/settings.json` (`maxConcurrentRuns`).

## 3. GigaChat (Сбер): бесплатно, без карты

1. Войдите в личный кабинет Studio на developers.sber.ru через СберID, создайте проект «GigaChat API» и получите **ключ авторизации** (его показывают один раз — сохраните).
2. Скачайте корневой сертификат Минцифры и положите его в `certs/` — инструкция в `certs/README.txt`. Прораб доверяет ему **только** при обращении к GigaChat; проверку сертификатов для остальных сайтов он не отключает.
3. Скопируйте `.env.example` в `.env` (Windows: `copy .env.example .env`; macOS/Linux: `cp .env.example .env`) и впишите ключ после `GIGACHAT_AUTH_KEY=` — без кавычек и пробелов.
4. В `config/providers.json` у провайдера `gigachat` поставьте `"enabled": true`.
5. Список имён моделей вашего ключа: `npm run gigachat-models`. Имя вписывается в поле `model`. В конфиге стоит `GigaChat-2-Pro` — имя из документации Сбера; проверьте, что оно есть в списке.

Бесплатный тариф для физлиц отвечает **в один поток** — Прораб сам ставит запросы в очередь (`maxConcurrent: 1`). Получит ли новый аккаунт бесплатный пакет, видно при регистрации: с 1 сентября 2026 Сбер направляет новых клиентов оплачивать работу на cloud.ru.

## 4. Z.ai (по желанию)

Модели GLM-Flash по документации Z.ai бесплатны, карта не нужна. **Доступность API из России я не проверял.** Чтобы попробовать: получите ключ на платформе Z.ai API, впишите его в `.env` (`ZAI_API_KEY=`), включите провайдера `zai` в `config/providers.json`. Если связи нет, пул пометит провайдера недоступным и пойдёт дальше по списку.

## 5. Управление с телефона

```
npm start -- --lan
```

В терминале появится вторая ссылка — для телефона. Откройте её в браузере телефона (он должен быть в той же Wi-Fi сети). Дальше: поставить задачу, увидеть ход работы, **разрешить или отклонить** действие, остановить всех кнопкой «⛔ Стоп всех».

- Ссылка содержит токен — это пароль. Не показывайте её.
- Страница работает по обычному HTTP, поэтому **включайте `--lan` только дома**, не в кафе и не в гостиницах: в чужой сети трафик могут подслушать.
- Это обычная страница, а не устанавливаемое приложение (для этого нужен HTTPS). «Добавить на главный экран» сделает ярлык.
- Windows может спросить про брандмауэр — разрешите доступ для частной сети.
- Вне дома (мобильный интернет) это не заработает, и это не баг: при ограничениях мобильной сети доступны только российские сервисы из «белого списка», а зарубежные туннели не гарантируются.

## 6. Как это устроено

```
Браузер (компьютер / телефон)
   │  страница web/ ── задачи, разрешения, журнал (события приходят потоком SSE)
   ▼
src/server.js ── защита: токен, проверка Host и Origin, только JSON
   ▼
src/app.js ── собирает всё вместе
   ├── src/agent/runner.js ── ЦИКЛ АГЕНТА
   │      1. спросить модель, что делать
   │      2. если нужен инструмент: дождаться «Разрешить» (если нужно) и выполнить
   │      3. если инструмента нет — это ответ, конец
   │   ├── tools.js       ── инструменты: список файлов, чтение, запись, правка, команда
   │   ├── approvals.js   ── очередь «Разрешить / Отклонить»
   │   └── runs.js        ── журнал запусков (data/runs/)
   └── src/pool/pool.js ── ПУЛ МОДЕЛЕЙ: идёт по провайдерам сверху вниз,
          │               пропускает выключенных, без ключа, на паузе и исчерпавших лимит
          ├── providers/openai.js   ── Ollama, Z.ai и любые OpenAI-совместимые
          ├── providers/gigachat.js ── GigaChat: токен на 30 минут, сертификат, functions
          └── quota.js              ── расход за день (data/quota.json)
```

| Где | Что |
|---|---|
| `config/settings.json` | порт, рабочая папка агентов (`workspace`), предел одновременных запусков (`maxConcurrentRuns`), открывать ли браузер |
| `config/providers.json` | реестр моделей: что включено, адрес, имя модели, где обрабатываются данные |
| `agents/<имя>/agent.json` + `SKILL.md` | агент: настройки и инструкции обычным текстом |
| `.env` | ключи (в git не попадает) |
| `data/` | всё, что программа записывает: журналы, расход, токен входа, резервные копии файлов |
| `src/` | код программы |
| `web/` | страница: `index.html`, `style.css`, `app.js` (все тексты интерфейса — в словаре `T` вверху), `theme.js`, шрифт Inter в `fonts/` |
| `test/` | автотесты |

**Рабочая папка.** По умолчанию это `workspace/` внутри проекта. Чтобы агенты работали с вашими файлами, впишите свой путь в `config/settings.json`. В Windows пишите со слэшами: `"workspace": "C:/Users/Имя/сайт"`.

**Резервные копии.** Перед каждой заменой файла старая версия кладётся в `data/backups/<запуск>/`. Откат — скопировать файл обратно.

## 7. Безопасность: что защищено и чего нет

Защищено:
- сервер слушает только этот компьютер; другие устройства — лишь с `--lan`;
- без токена сервер ничего не отдаёт; проверяются заголовки `Host` и `Origin`, команды принимаются только в JSON — чужой сайт не может отдать приказ вашему Прорабу;
- агент не выйдет за рабочую папку: ни через `..`, ни через абсолютный путь, ни через символическую ссылку;
- чтение — свободно; запись файлов — только с разрешением (кроме агентов в режиме `auto`); **запуск команд — всегда с разрешением**;
- текст от модели вставляется в страницу как текст, а не как HTML;
- команды, которые запускает агент, **не видят ключей**: из их окружения убираются переменные с `KEY`, `TOKEN`, `SECRET`, `PASSWORD` в имени и все ключи из `config/providers.json` (иначе вывод команды, например `env`, ушёл бы модели и в журнал на диске);
- файлы читаются и меняются **только в UTF-8**. Файл в Windows-1251, UTF-16 или бинарный, а также больше 1 МБ агент не трогает — иначе он испортил бы текст. Знак BOM и Windows-переводы строк (CRLF) в файле сохраняются; файл с перемешанными переводами строк не правится;
- в Windows отклоняются имена-устройства (`CON`, `NUL`, `COM1` и подобные) и имена с двоеточием или точкой на конце.

**Чего нет — знайте об этом:**
- **Содержимое файлов, которые читает агент, отправляется выбранной модели.** Для облачных (GigaChat, Z.ai) это значит «уходит за пределы компьютера». Для личных файлов ставьте агенту `"localOnly": true` — тогда используются только локальные модели.
- Команда, которую вы разрешили, выполняется с вашими правами и без «песочницы». Читайте команду перед нажатием «Разрешить».
- Защита от «подсовывания указаний» внутри файлов — только просьба в инструкции модели и ваше подтверждение. Подтверждение — главный предохранитель.
- Ключи лежат в файле `.env` открытым текстом. Хранилище ключей Windows/macOS/Linux — следующий этап.

## 8. Как расширять

- **Новый агент:** скопируйте папку из `agents/`, поправьте `agent.json` и `SKILL.md`, перезапустите программу. В `tools` перечислены доступные инструменты, `mode` — `manual` (спрашивать про любую запись) или `auto`, `models` — цепочка провайдеров (пусто = все включённые по порядку), `localOnly` — только локальные модели. Агенту, которому нужны команды, добавьте `run_command`.
- **Новая OpenAI-совместимая модель:** добавьте запись в `config/providers.json` по образцу `local` (тип `openai`).
- **Новый тип провайдера:** файл в `src/pool/providers/` с функцией `create…Provider`, регистрация — в `src/pool/registry.js`.
- **Новый инструмент:** запись в `TOOLS` в `src/agent/tools.js` (у каждого есть `risk`, `description`, `parameters`, `describe`, `run`) и его имя в `agent.json`.

## 9. Тесты

```
npm test
```

Тесты не требуют интернета, ключей и моделей: они запускают «притворную» модель и «фальшивый GigaChat» с тестовым сертификатом (`test/fixtures/`, только для тестов).

**Проверка в вашем браузере.** Автотесты проверяют логику, но не внешний вид. Скрипт открывает страницу в настоящем Chrome или Edge на телефонных и компьютерных размерах, в обеих темах, проходит сценарий «задача → разрешение → результат» настоящими кликами и ищет ошибки в консоли браузера. Один раз выполните `npm install --no-save puppeteer-core`, затем `npm run browser-check`. Если браузер не найден, укажите путь в переменной `CHROME_PATH` (подсказка — в начале `scripts/browser-check.mjs`). Скрипт работает на временных папках и не трогает ваши данные.

## 10. Известные ограничения версии 0.2

- Агентов создают копированием папки; редактор агентов в интерфейсе — следующий этап.
- Ответы модели приходят целиком, а не по буквам (потоковая передача не реализована).
- За один шаг выполняется один вызов инструмента: если модель просит несколько, берётся первый, остальное она попросит на следующем шаге.
- В Windows вывод команд может показываться «кракозябрами»: консоль использует старую кодировку.
- Журнал запусков и резервные копии в `data/` сами не удаляются — при необходимости чистите папку вручную.
- Файлы не в UTF-8 (например, старые тексты в Windows-1251) агент не обрабатывает: это сознательный отказ ради сохранности данных.
- Нет «экзамена» моделей, автосжатия длинного контекста и планировщика по времени сброса лимитов (всё это — в концепции, этапы 2–3).
- Единый исполняемый файл и оболочка с иконкой в трее не делались.
- Лицензия проекта не выбрана — решите сами (например, MIT). Шрифт Inter распространяется по лицензии SIL OFL (`web/fonts/Inter-LICENSE-OFL.txt`).

## 11. Что проверено

Проверено (Node 22.22.2, Linux; Chromium 153 в режиме headless):
- **75 автотестов**, пять прогонов подряд без сбоев: забор вокруг рабочей папки; пул (переключение, паузы, лимиты, очередь «по одному», режим «только локально»); цикл агента (разрешение, отказ, остановка, лимит шагов, ошибки инструментов); оба адаптера моделей (GigaChat — на локальном «фальшивом» сервере с тестовым сертификатом); защита сервера (токен, Host, Origin, JSON); кодировки, CRLF, BOM, секреты в окружении команд; перезапуск и сбои записи журнала; совпадение README и кода; сквозной сценарий по HTTP;
- **страница в настоящем браузере** (Chromium 153, эмуляция телефона и компьютера): 33 проверки — сценарий настоящими кликами, события в реальном времени, шрифт Inter, светлая и тёмная темы и их запоминание, нет горизонтальной прокрутки на ширинах 320–1920 px, вкладки внизу на телефоне, кнопки не меньше 44 px, нет нарушений политики безопасности и ошибок в консоли; журнал на 805 записей при замедлении процессора в 4 раза не вешает страницу (10 МБ памяти страницы, вся страница с шрифтами — 99 КБ);
- обычный запуск без модели: программа стартует, сервер закрыт токеном, агент честно сообщает, почему модели нет.

**Не проверено:**
- настоящий телефон и другие браузеры: Safari, Firefox, Chrome на Android/iOS (проверена эмуляция в Chromium; свой браузер проверьте командой `npm run browser-check`);
- Windows и macOS: код кроссплатформенный, но там не запускался (особенно `run_command`, открытие браузера, пути с кириллицей, защита от имён-устройств Windows — проверена только логика выбора имён);
- реальный GigaChat: формат сверен с документацией Сбера (страницы обновлены 17.07.2026), но не с живым сервисом;
- реальные модели Ollama: насколько надёжно конкретная модель вызывает инструменты;
- работа по Wi-Fi между компьютером и телефоном (сетевой режим `--lan` проверен только на этом же компьютере).

Если что-то не работает, пришлите текст из окна терминала (без ключей и токенов) — разберёмся.
